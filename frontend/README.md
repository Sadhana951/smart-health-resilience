# Smart Health Resilience - Frontend Application

A production-grade React + TypeScript + Vite web application engineered with a futuristic healthcare intelligence command center design system.

## Technologies Used
- React 19 + TypeScript
- Vite
- Tailwind CSS
- Lucide React Icons
- Leaflet & React-Leaflet
- Recharts
- Canvas Confetti
- Web Speech API (Speech-to-Text & Text-to-Speech)

## Features Included
- **Landing Page (`/`):** 3D stylized India healthcare network Canvas, animated problem transformation, and 8-step workflow.
- **Command Center Dashboard (`/dashboard`):** Animated metric cards, interactive map preview, live critical actions feed.
- **PHC Network (`/phc-network` & `/phc/:id`):** Multi-layer geospatial map, search, filter by state/district/risk, facility detail drawer.
- **Inventory (`/inventory`):** Comprehensive 12-medicine stock register with days-remaining countdown and stock-level bars.
- **Forecasts (`/forecasts`):** 7/14/30-day Bayesian ARIMA demand trajectories with 95% confidence intervals.
- **Alert Center (`/alerts`):** Triage grouping into Critical, Warning, and Strategic Surplus notices.
- **Redistribution Engine (`/redistribution`):** Automated shortage <-> surplus pairing with live dispatch tracking timeline.
- **AI Assistant (`/assistant`):** HealthResilience AI conversational interface with suggested queries.
- **Multilingual Voice (`VoiceAssistantModal`):** Speech-to-Speech support for English, Hindi, and Odia.
- **Emergency Simulation (`/simulation`):** Disaster stress testing (Flood, Dengue, Heatwave, Outbreak, Shortage).
- **Federated Learning (`/federated-learning`):** Privacy-preserving 3-node training demo with loss curve.

## Running Locally
```bash
npm install
npm run dev
```
Runs at `http://localhost:5173`.
